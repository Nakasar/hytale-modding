# Vrilles (piège)

> 📷 Capture en jeu à venir. Elles reprennent les racines du sort vanilla d'enracinement.

**Piège** · id `Nakasar_Pumpkin_Tendril`

Les racines qui jaillissent sous vos pieds quand la [Citrouille géante](citrouille-geante.md) lance son **piège de vrilles**. Elles n'attaquent pas : elles vous tiennent.

## Fiche

| | |
|---|---|
| Points de vie | **12** (un ou deux coups) |
| Effet | [Enraciné](../effets.md#enraciné) : impossible de bouger tant qu'elles vivent |
| Durée maximale | **20 s** |
| Faiblesse | feu ×2 |

## Fonctionnement

- Une touffe pousse aux pieds de **chaque** ennemi touché par le piège (joueurs, chasseurs de vampires, créatures dominées).
- Vous êtes libéré quand elle est détruite, quand vous mourez, ou au bout de 20 s.
- Les créatures du Comté ne sont jamais piégées.

## Butin

Aucun.
